# Generic Artifact And CAT/DAT Pipeline Implementation Plan

**Status:** VERIFIED 2026-07-24. Review forced one safety correction: staging output was moved from
`<Mod Workspace>/<modId>` to `<Mod Workspace>/.forge-builds/loose/<modId>` so an atomic artifact swap
can never replace the source checkout.

> **For Agent:** Follow the repository Universal AI Task Workflow. Use scratch fixtures only until the
> real-game write gate is separately authorized.

**Goal:** Make Forge build complete loose and CAT/DAT artifacts for arbitrary X4 mods without loading
large opaque files into the browser workspace or hardcoding mod-specific paths.

**Architecture:** Add a disk-backed artifact planner/materializer and a streaming CAT/DAT writer beside
the existing reader. Adapt the existing workspace emitter into this plan, then make deployment consume
the same complete inventory. Generated output owns only its declared paths; all other included source
files stream unchanged.

**Tech stack:** TypeScript, Node `fs` streams/synchronous positioned I/O, `crypto` hashes, existing
`x4CatDat` reader, existing oracle registry and route/e2e harnesses.

## Task 1: Artifact inventory model

**Files:**
- Create `src/lib/artifactPipeline.ts`
- Modify `src/types.ts` only if workspace-level artifact configuration is required

1. Define plan entry, rule, report, conflict, and verification types.
2. Implement a bounded, symlink-safe source walk and normalized/case-fold collision detection.
3. Add universal development exclusions plus `.forgeartifact.json` project overrides.
4. Merge generated output claims with source inventory; unclaimed regular files become streamed copies.
5. Add a pure/self-contained oracle for ownership and negative paths.

## Task 2: Scratch materializer

**Files:**
- Modify `src/lib/artifactPipeline.ts`

1. Materialize into a new empty scratch directory.
2. Stream source-owned files in bounded chunks; write generated bytes directly.
3. Hash source and destination and fail on missing/mismatched bytes.
4. Produce a machine-readable artifact report with every included/excluded/runtime/conflict path.

## Task 3: Streaming catalog writer and verifier

**Files:**
- Modify `src/lib/x4CatDat.ts`

1. Add a packer interface and deterministic native writer.
2. Stream entries into DAT while computing MD5 and recording CAT metadata.
3. Partition deterministically by configurable volume bytes.
4. Reopen with the existing reader and verify pair, offsets, sizes, hashes, and inventory.
5. Extend the existing CAT/DAT selftest with spaces, Unicode, empty, multi-volume, large binary, missing
   source, and tampered-DAT failures.

## Task 4: Workspace/deploy integration

**Files:**
- Modify `server.ts`
- Modify route contract documentation/selftests as needed

1. Replace omitted-file loss with source-backed artifact planning.
2. Route `/api/fs/write` and creation/deletion mutations to `modWorkspacePath`, never the deployed
   `filesystemPath`.
3. Add an authenticated scratch artifact build endpoint supporting loose/catalog formats without an
   arbitrary output path.
4. Make deploy compilation consume the same complete plan while preserving existing validation/source
   sync gates.
5. Keep existing response fields additive-compatible.

## Task 5: Hostile arbitrary-file mod

**Files:**
- Create `scripts/artifact-pipeline-check.ts`
- Modify `scripts/oracle-integration.mjs` or selftest registry wiring
- Modify `package.json`

Generate the fixture under the OS temporary directory with:

- valid `content.xml`, MD, AI, library, translation, and UI samples;
- text just below/above 256 KiB and above the old total budget;
- deterministic multi-megabyte binary;
- empty, extensionless, unknown-extension, Unicode/space, deep, duplicate-basename files;
- CRLF/LF, UTF-8 BOM, and arbitrary non-text bytes;
- `.git`, editor-agent metadata, explicit exclusions, runtime-owned entries;
- symlink/reparse and case-collision negative fixtures where the host supports them.

Assert loose and packed inventory/hash parity, catalog splitting/reopen, exclusion reporting, and all
negative failures. Remove the temporary fixture in `finally`.

## Task 6: Validation

Run and record:

1. `npm run typecheck`
2. `npm run lint`
3. focused artifact/CAT selftest
4. hostile fixture test
5. `npm run test:oracles`
6. `npm run test:routes`
7. `npm run test:e2e` after the machine-state gate
8. `npm run build`
9. extension build/stage/probe if shipped bundle contents change
10. `npm run precommit:check`
11. scratch negative path: tamper DAT, remove source, inject traversal/symlink, confirm rejection

No real G-drive deployment is an acceptance method for this unit. A later live test needs a separate
write brief and explicit authorization.

## Rollback

Remove the new artifact module/check, revert the reader/deploy adapters, and retain the existing loose
compiler. All generated fixtures live under OS temp and are deleted automatically. No existing mod or
game data is used as a mutation target.
