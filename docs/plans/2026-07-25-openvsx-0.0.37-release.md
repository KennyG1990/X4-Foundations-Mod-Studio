# OpenVSX 0.0.37 Release Plan

**Status:** VERIFIED

## PLAN

- **Bounded unit:** package and publish the already-verified B76 generic artifact/CAT-DAT pipeline as stable OpenVSX version 0.0.37, then commit and push the exact published source.
- **Assumptions:** OpenVSX currently serves 0.0.36; `OVSX_PAT` is present in the gitignored `.env.local`; `main` and `origin/main` both begin at `7d71c00`.
- **Authority:** Ken's 2026-07-25 publish request; `vscode-extension/PUBLISHING.md`; publish-before-commit project rule; B76 VERIFIED evidence in `SESSION-HANDOFF.md` and `ROADMAP.md`.
- **In scope:** restore only the two graphify-mutated historical evidence PNGs to their pre-B76 parent bytes (the B76 commit accidentally captured the churn); bump the extension to 0.0.37; add curated release notes; generate changelog; rebuild/stage/probe/package; inspect/hash the VSIX; publish; verify the registry version and public download hash; update close records; commit and push.
- **Out of scope:** installing into Antigravity on Ken's behalf, real X4/game-directory deployment, B77 graphify root-cause work, unrelated cleanup, Microsoft Marketplace publication.
- **Risks/authorization:** OpenVSX publication is externally visible and irreversible at this version number; explicitly authorized. Git commit/push follows the delegated project release policy. The PAT must never be printed. Historical PNG restoration is limited to two baseline-proven graphify mutations. No game/mod/config path is written.
- **Rollback/recovery:** before publish, stop on any red gate and leave 0.0.36 public. After publish, do not delete 0.0.37; fix forward with a higher version if required. Git remains uncommitted until OpenVSX accepts the package.

## ACCEPTANCE

1. Extension manifest and changelog identify stable 0.0.37 with accurate B76 user-facing notes.
2. Precommit, production build, extension build, staged sidecar probe, and stable VSIX packaging pass.
3. Packaged-content inspection confirms only allowed extension/app artifacts and no secrets, sourcemaps, config, runtime state, historical evidence PNGs, or unrelated test files.
4. Local VSIX SHA-256 is recorded; OpenVSX versions API lists 0.0.37; public VSIX download SHA-256 equals local.
5. Negative path: unauthenticated staged config remains 401; package scan finds zero forbidden payloads; no publish occurs if any gate is red.
6. The exact published release state is committed and pushed, with `origin/main == HEAD`.
