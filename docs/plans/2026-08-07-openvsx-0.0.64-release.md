## AAR

- Triggers: fresh-eyes review required a Luna wording correction; two coordinator PowerShell JSON reads treated the
  package-lock's empty root key as an object property before being corrected with hashtable parsing; the recurrence
  triggered the session degradation call. The first public-parity script did not stop on an HTTP
  `404` and then passed null to an ambiguous `HashData` overload; OpenVSX accepted publication before public indexing;
  and the first registry source-tree query used the transferred repository's old `master` name, returned `404`, and
  was corrected by reading the current `main` default branch from repository metadata. Final full diff review found
  the generated changelog EOF defect after upload. Archive byte inspection proved the accepted VSIX embeds the
  original byte; an attempted restoration through `apply_patch` normalized it away again, exposing the exact-input
  mismatch rather than safely restoring package-source identity.
- Sustain: publish-before-commit preserved exact source/archive identity; package inspection, staged-sidecar probing,
  stable-channel checks, and no-republish discipline all held.
- Improve work/approach: public verification scripts must make HTTP success a hard precondition before parsing or
  hashing and must type downloaded content explicitly as `[byte[]]`.
- Improve tools: publisher acknowledgment is not a downloadable-artifact oracle; retain bounded public API and exact
  archive-hash readback as separate required gates. Changelog generation selftests must include repository-level
  whitespace/diff validation before package creation, not just semantic note equality.
- Highest-risk evidenced weakness: OpenVSX publication visibility is asynchronous. Its implemented long-running
  security scanners can keep an accepted upload unavailable beyond their default timeout while other releases flow,
  so a successful publisher exit alone can create a false release claim. The bounded fix is the existing
  latest/version/download/byte-parity gate, with no retry publish; an unresolved hold requires registry disposition.
